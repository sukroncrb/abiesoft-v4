Dokumentasi Resmi AbieSoft Framework v4.0

AbieSoft v4 adalah Hybrid High-Performance Web Framework yang menggabungkan kecepatan pemrosesan I/O non-blocking dan konkurensi native Golang dengan keluwesan bisnis serta kekuatan templating view PHP 8.2.

⚡ Golang Gateway :3000 (Publik)
🐘 PHP Backend :8002 (Internal)
🛡️ Auto Port Cleaner Zero Zombie Port

01 Arsitektur Gateway Hybrid (Bypass vs Proxy)

Bagaimana alur request diproses secara pintar tanpa membebani PHP.

Alur Distribusi Request (HTTP Routing Pipeline)

Client Request (Browser / Mobile / Curl) → http://127.0.0.1:3000
↓ Diterima oleh AbieSoft Go Gateway Engine
Rute: /api-go/* DIRECT BYPASS

Ditangani 100% langsung oleh Native Go Mux di src/Modules/handler.go.

  • Bypass PHP sepenuhnya (Zero overhead PHP)
  • Goroutine concurrency tingkat tinggi
  • Respon latency mikrodetik
  • Akses langsung pool database MySQL native
Rute: /api/* & Halaman Web REVERSE PROXY

Diteruskan (Reverse Proxy) ke PHP Built-in Server Port :8002.

  • Dikelola oleh routes/web.php
  • Rendering Template Latte UI
  • Middleware, Auth, dan Session PHP
  • Action-Domain-Responder (ADR) architecture

02 Struktur Direktori Proyek 

abiesoft/
├── database/
│   └── schemas/              # Berkas migrasi database SQL otomatis
├── public/                   # Web public root (index.php, assets css/js)
├── routes/
│   └── web.php               # Pendaftaran rute PHP Core & Web View
├── src/
│   ├── GoModules/            # ⚡ Modul Golang Native (Dto, Services, Actions, Tests)
│   ├── Modules/              # 🐘 Modul PHP Core (Dto, Services, Actions, Tests)
│   │   └── handler.go        # Sentral routing Direct Go engine (RegisterRoutes)
│   └── Shared/               # Helper shared antara PHP & Golang
├── sys/
│   ├── Console/              # Engine CLI 'php abiesoft' & Commands
│   ├── Database/             # Database connection wrapper (PDO MySQL)
│   ├── Http/                 # Router PHP internal & Middleware runner
│   ├── pigo/                 # Binary & source code Golang Engine Gateway
│   │   ├── bin/pigo-engine   # Hasil binary build engine Go
│   │   └── pigo_engine.go    # HTTP Gateway & Reverse Proxy implementation
│   ├── Testing/              # Base TestCase assertion library
│   └── View/                 # Template View Renderer (Latte)
├── templates/                # Template Latte halaman UI (pages)
└── testing/                  # Tempat testing aplikasi kustom

03 Instalasi & Persiapan Proyek

1. Clone & Konfigurasi .env

Salin file sampel dan sesuaikan kredensial database:

cp env_sample .env

2. Menginstal Dependensi (Urutan Penting)

Jalankan go mod vendor terlebih dahulu, kemudian composer update:

# 1. Download vendor modul Golang
go mod vendor
# 2. Update pustaka dependensi PHP
composer update

3. Build Go Engine & Import Database

php abiesoft build
php abiesoft database:import

04 Menjalankan Server (Start)

Cukup jalankan satu perintah konsol untuk menyalakan kedua engine secara simultan:

php abiesoft start
✔ Port 3000 & 8002 otomatis dibersihkan (Anti-Zombie Port).
✔ Golang Gateway berjalan di http://127.0.0.1:3000
✔ PHP Core Backend berjalan di http://127.0.0.1:8002
✔ Graceful Shutdown: Tekan Ctrl+C untuk mematikan kedua proses sekaligus.

05 Melihat Daftar Rute (Route)

Perintah route memindai dan menyajikan seluruh rute aktif, baik rute PHP Core maupun rute Golang Native Direct Bypass:

php abiesoft route

06 Generator Modul (make:module)

Membuat modul komplit lengkap dengan DTO, Services, Actions, Schema SQL, Rute & Unit Test.

Modul PHP Core (Default) PHP Core
php abiesoft make:module users
  • Schema: database/schemas/*_users_table.sql
  • DTO: src/Modules/Users/Dto/UsersData.php
  • Repo: src/Modules/Users/Services/UsersRepository.php
  • Actions: Index, Get, Post
  • View Latte: templates/pages/users/index.latte
  • Unit Test: src/Modules/Users/Tests/UsersTest.php
  • Auto-inject ke routes/web.php
Modul Golang Native (--go) Golang Direct
php abiesoft make:module users --go
  • Schema: database/schemas/*_users_table.sql
  • Go DTO: src/GoModules/Users/Dto/users_dto.go
  • Go Service: src/GoModules/Users/Services/users_service.go
  • Go HTTP Actions: src/GoModules/Users/Actions/users_action.go
  • Go Test: src/GoModules/Users/users_test.go
  • Auto-inject rute & import ke src/Modules/handler.go
  • Auto-compile Go binary otomatis tanpa build manual

07 Generator Komponen Mandiri (Action, Service, DTO, Test)

Gunakan flag --go jika ingin membuat komponen khusus Golang.

1. Membuat Action (make:action)

# PHP Action: php abiesoft make:action users detail

src/Modules/Users/Actions/DetailUsersAction.php

# Golang Action: php abiesoft make:action users detail --go

src/GoModules/Users/Actions/detail_action.go

2. Membuat Service / Repository (make:service)

# PHP Repository: php abiesoft make:service users auth

src/Modules/Users/Services/AuthRepository.php

# Golang Service: php abiesoft make:service users auth --go

src/GoModules/Users/Services/auth_service.go

3. Membuat Data Transfer Object (make:dto)

# PHP DTO: php abiesoft make:dto users login

src/Modules/Users/Dto/LoginData.php

# Golang DTO: php abiesoft make:dto users login --go

src/GoModules/Users/Dto/login_dto.go

4. Membuat Unit Test (make:test)

# PHP Unit Test: php abiesoft make:test users auth

src/Modules/Users/Tests/AuthTest.php

# Golang Unit Test: php abiesoft make:test users auth --go

src/GoModules/Users/auth_test.go

08 Penghapusan Komponen (Delete)

Setiap perintah delete dilengkapi proteksi konfirmasi keamanan (y/n) sebelum mengeksekusi.

Menghapus Modul Lengkap (delete:module)

# Hapus Modul PHP: php abiesoft delete:module users

Membersihkan folder PHP, template view Latte, rute di web.php, dan tabel SQL.

# Hapus Modul Golang: php abiesoft delete:module users --go

Membersihkan folder Go, rute di handler.go, auto-recompile Go binary, dan tabel SQL.

Menghapus File Satuan

Komponen Target PHP (Default) Target Golang (--go)
Action php abiesoft delete:action users detail php abiesoft delete:action users detail --go
Service php abiesoft delete:service users auth php abiesoft delete:service users auth --go
DTO php abiesoft delete:dto users login php abiesoft delete:dto users login --go
Unit Test php abiesoft delete:test users auth php abiesoft delete:test users auth --go

09 Sistem Unit Testing Otomatis

Menguji modul PHP dan Golang secara terpadu langsung dari konsol.

# Menjalankan Semua Test (PHP + Go): php abiesoft test
# Test Modul PHP Spesifik: php abiesoft test users
# Test Modul Golang Spesifik: php abiesoft test users --go
# Test Seluruh Modul Golang: php abiesoft test --go
=== RUN TestUserCreation
✔ --- PASS: TestUserCreation (0.00s)
• Menjalankan suite: UsersTest
✔ PASS: testDtoCreation()
🎉 Seluruh Unit Test Berhasil (PASS)!

10 Manajemen Database & Konvensi Skema

Setiap kali modul dibuat dengan make:module, file skema SQL otomatis disimpan di database/schemas/. Jalankan perintah berikut untuk mengimpor skema yang belum terdaftar:

php abiesoft database:import
📌 Konvensi Standar Kolom AbieSoft: Semua tabel database di AbieSoft menggunakan nama kolom standar:
  • id (INT AUTO_INCREMENT PRIMARY KEY)
  • uuid (VARCHAR(36))
  • dibuat (TIMESTAMP DEFAULT CURRENT_TIMESTAMP)
  • diedit (TIMESTAMP NULL ON UPDATE CURRENT_TIMESTAMP)
  • dihapus (TIMESTAMP NULL DEFAULT NULL)

11 Kompilasi Golang Engine (Build)

Meskipun make:module --go dan delete:module --go otomatis melakukan recompile, Anda dapat mengompilasi binary Golang secara manual kapan saja dengan:

php abiesoft build

Hasil kompilasi binary disimpan di sys/pigo/bin/pigo-engine.

php abiesoft delete:test <mod> [nama] [--go] Menghapus file Unit Test tertentu
